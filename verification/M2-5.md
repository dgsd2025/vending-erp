## 6. 坑(each)

1. **Playwright `is_mobile=True` 假"被遮挡"**:mobile 模拟的视觉/布局视口分离导致命中检测坐标漂移(bounding_box 与页面内 getBoundingClientRect 差了整整一个 scrollY 段),点击 30s 超时;页面内 `elementFromPoint` 证明按钮真实可点。解法:验收用 375×812 纯 viewport(media query 全部照常驱动),不开 `is_mobile`
2. **定位滚动 `behavior:'smooth'` 干扰自动化**,且扫码枪连续扫时动画反而拖慢——改瞬时 `scrollIntoView({block:'center'})`
3. **离线黄条被手机固定顶栏盖住**(sticky top:0 z-30 vs fixed 顶栏 z-40):截图审查才发现,改手机态 `top:56px` 贴顶栏下
4. **对话框 footer 桌面按钮泄漏到手机**造成双"标记已执行"——footer 打印/执行加 `.pk-desktop` 隐藏,手机只留正文大按钮+关闭
5. **docker exec mysql 默认 latin1 写坏中文**:重置测试数据把 `已生成` 写成 mojibake,前端状态匹配全失效;必带 `--default-character-set=utf8mb4`
6. **盘点明细不带条码**(只有 skuCode):扫码定位需商品档案 `barcode→productId` 映射,页面挂载时拉一次(拉失败静默降级为编号/名称匹配,不阻塞盘点)
7. `.side-mask` 中心点在抽屉(216px)底下,测试点遮罩要指到右侧空白坐标——真机用户行为本来就是点空白处
