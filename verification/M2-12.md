## 六、坑(each)

1. **vend_dev 机器账大面积为负**(无快照、销售>补货记录):负账直接进 (R,S) 会虚增采购量 → 引擎统一 `max(机内,0)` 参与计算,并在 calc_detail 写红灯"机器账为负,建议盘点"。机器侧同理,建议=容量−max(现有,0),且不超货道容量硬约束。
2. **统计窗口锚「数据截至日」而非今天**:数据晚导 6 天若锚今天,28 天窗口尾部全是 0,日均被稀释 21%;锚 MAX(biz_time) 后真数据 d̄ 正确,页面另用 staleDays>3 变灰强制先导(mockup 原样)。
3. **S 取整口径**:359.6 若不取整,Q=279.6 与调研算例 280 对不上 → 定死 S=ceil(周期需求+SS),Q、整箱再各自向上取整,单测逐项锁死。
4. **MyBatis map 查询 NULL 列会丢 key**(机器侧无销量行没有 avgDaily 字段):前端全部用 `?? / == null` 兜底;验收脚本里 python 也要 .get(教训:直接 `r['avgDaily']` KeyError)。
5. **迁移编号并行冲突**:并行 task 票已建 V1.0.6,本票 V1.0.3 幸好在 vend_dev 于 1.0.6 之前被 apply;Flyway 未开 out-of-order,**后续并行票务必先看 flyway_schema_history 再定版本号**。
6. **偶发 POST 请求整机挂起**(重启 java 进程后消失):8089 旧进程出现"GET 正常、POST 挂起且后端零日志"的怪象约 8 分钟后自愈,jstack 显示 worker 全 idle,疑与本机多后端并行/长连接状态有关,非代码问题;重启后 3 连发 POST 全过。遇到同症状先重启后端再排查。
7. **浏览器面板滚动截图会花屏**(整页灰块/侧栏错位):对照 /inventory 老页同样复现,是面板截图伪影不是页面 bug;截图用 Playwright(full_page)或把视口拉高代替滚动。
8. **slow min/max、llm_model 属 config 新列**:老库要 apply V1.0.3(ALTER 3 列),否则 config upsert 丢字段;vend_dev/vend_test_replenish 均已确认 `SHOW COLUMNS` 含新列(Flyway success=1)。
