## 坑(each)

1. **共享 backend/target 并行竞态**:三张并行票(M3-2/M3-6/本票)同仓跑 mvn——我一次 `mvn clean` 清了别人正在跑的 surefire,别人 recompile 也把我 8099 运行中 JVM 的 target/classes 换掉导致进程死+一次 500。**修法:测试/起服一律加 `-Dmaven.build.directory=<独立目录>`,并且并行期禁 `mvn clean`**(8099 重启轮已用独立目录,复测通过)。
2. **全仓回归一次 3 个 DeadlockLoserDataAccess(Scenario10)**:并行会话同时打 vend_test_regression 库造成 MySQL 死锁,单跑该类 8/8 绿,重跑全仓 252 全绿——是环境竞态不是代码问题。
3. **zsh 不分词**:`H='-H a -H b'; curl $H` 在 zsh 里是一个参数,header 全串成一坨 → 账户建失败还不报错(-s 吞了)。curl 参数必须逐个写引号。
4. **迁移版本号避让**:并行票已占 V1.0.8/V1.0.9,本票直接取 V1.0.10(flyway out-of-order:true 三票乱序共存无冲突)。
5. **模板里带类型标注的内联箭头函数会炸 vue-tsc**:`:row-class-name="({ row }: { row: X }) => …"` 报 TS1005——抽成 script 里的具名函数 `diffRowClass` 即过。
6. **el-table 宽列在 800px 视口被裁**:差异/出口列要横向滚动才可见(截图验收时先 scroll right);后续可给关键列加 fixed="right"(M2-3 坑7 同尺,本票未改避免面板列过挤)。
7. **浏览器面板截图黑屏**:JS scrollIntoView 后 pane 截图偶发全黑(渲染捕获 bug),force 重导航后恢复;黑屏时用 DOM 文本 dump 留证据。
