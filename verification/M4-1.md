## 一、接口清单(6 只读 GET · `/v1/bi`)

| 接口 | 说明 | 关键口径 |
|---|---|---|
| `GET /matrix?month&dim` | 维度×指标矩阵,dim=machine/category/product/slot/timeslot/supplier 六维 | 取不到的格子返回 null,前端显「—」 |

| `GET /basket?month` | 客单价 + 连带 TOP 组合 + 支付方式占比 | 会话键=machine+biz_time(order_no 受 uk_sale_order 约束天然唯一,跨SKU不可能共享) |

## 五、坑 each

1. **shell 无法解析变量里的 CJK 路径**:`F="...智慧园区..."; ls "$F"` 报 No such file,但 `cd .../智慧园区 && ...` 字面量正常——变量传递时 zsh 对 CJK 字节处理异常。修法:命令里写字面路径 / 用 Read·Edit·Write 工具(路径可靠)。
2. **测试文件被并行票误删**:BiServiceTest.java Write 成功且首轮 mvn 已编译,复跑时 test/modules/bi 整目录消失(共享工作树 pdca/ai 恢复期活动)——重新 Write 恢复,主码 5 文件未受损。教训:共享树只等不改他人文件,自己的文件被动了就重建。
3. **docker mysql CLI 吞 CJK 字面量**:`WHERE order_type='正常'` 在 `docker exec mysql` 默认 charset 下匹配 0 行,导致"同秒多行组数=0"假象,险些误判 basket 连带为 bug。**必加 `--default-character-set=utf8mb4`**;应用侧 JDBC(UTF-8)一直正确(3487单/753多件)。
4. **连带「同订单」在本 schema 无法用 order_no**:`uk_sale_order(tenant,order_no,order_type)` 令两条正常单不能共享 order_no,跨SKU 连带信号永为0。改用 machine+biz_time 会话键(同秒同机=一次消费),真数据得 753 多件单、连带 TOP 组合可用。
5. **Java 8 target**:`maven.compiler.release=8`,禁用 `List.of`/无参 `orElseThrow()`(Java 9/10),改 `Arrays.asList`/`orElseThrow(AssertionError::new)`。
6. **共享 Browser pane 强竞争**:pdca 票同时在同一 pane 做验证,标签被反复导走。改用 `/bi?month=2026-07` 深链(顺带做成可分享能力),navigate 后立即截图/读 console,缩短竞争窗口。
