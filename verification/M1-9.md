## ④ 坑(每条一句话)

1. **vend_dev 的 dataAsOf 被当天真测单据顶到 2026-08**,报表默认月变成空月——驾驶舱加"回退最近有售月"、机器详情锚点改"该机最近一笔销售",否则历史数据全显 0。
2. **期初向导只导销售史、没有机器快照**,机器账推算全为负(67 个红灯)——这是数据事实不是 bug,机内库存卡/填充率遇负数显红色提示"缺快照锚点",不出假数。
3. doc_head 的来源列叫 **doc_source 不是 source_type**、货道表叫 **yc_vend_slot 不是 machine_slot**——mapper SQL 先 SHOW COLUMNS 再写,别按实体名猜表名。
4. mapper/service 里用 `ReportDtos.Xxx` 内部类必须 **import 外层类 ReportDtos**,只 import 内部类会报 "package ReportDtos does not exist"。
5. vite dev server 默认绑 **localhost(IPv6 ::1)**,Playwright 用 127.0.0.1 连会 ERR_CONNECTION_REFUSED——统一用 http://localhost:5178。
6. 本机 python playwright 首装会**清掉旧版本浏览器缓存再下 chromium-1223**,5 分钟起步,验收脚本前先装好。
7. 移除全局顶栏后,靠顶栏显示标题的页(导入/库存/报表)会"没头"——每页自带 ledger-crumb/title 才是与 mockup 一致的形态。
