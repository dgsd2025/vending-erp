## 三、坑 each(踩坑记录)

1. **Maven 默认吃 JDK26 → Lombok 1.18.30 编译崩**(`TypeTag :: UNKNOWN`)。本机装了 openjdk 17/26,`mvn -version` 运行时是 26。修:`export JAVA_HOME=.../openjdk@17` 再 `SERVER_PORT=8108 mvn spring-boot:run`。后端起服踩此需先切 JDK17。
2. **本月销售卡显「¥7 / 毛利率 -388%」**:原回退逻辑只在当月销售 `=== 0` 时回退,但当月(2026-08)有 ¥7 测试噪声单绕过判定,直接显失真数。修:回退阈值改为 `< ¥100`(自然日单机销售远高于此)。
3. **异常雷达全量 94 条铺满驾驶舱**:原组件无上限,首页会拉出 94 行。加 `:limit` prop(红灯优先排序 + 折叠计数),驾驶舱只吃 TOP 5。
4. **数据当前是「今日」快照(dataAsOf=2026-08-07)**:水印天然显绿色新鲜态,**超3天灰化红条**为逻辑守卫(`daysStale>3`),本次无过期数据可现场触发截图;逻辑已单测式走查(getter 纯函数),数据陈旧时自动生效。
5. **卡片是 `<div @click>` 非 `<a>`**:read_page interactive 抓不到,pixel click 又受视口缩放影响;最终用 Playwright `.click()` + `router.push` 异步等待验证跳转(同一 JS 调用内读 pathname 会拿到跳转前旧值)。
6. **共享浏览器 tab 池已满**:并行会话占了多个 dev server tab,复用 seed tab 走查(未新开 tab)。
