## 5. 坑记录

1. **今日流水笔数没有专用接口**:`pageFlows` 只支持记账期(YYYY-MM)筛选,不支持按天——取当月流水(size=200)前端按 `bizTime` 前 10 位=今天数。当月流水超 200 笔会少算,本量级(月 47 笔)安全;M4 若做资金趋势建议后端补 `?bizDate=` 参数。
2. **「杂支」空态差点假 PASS**:首轮筛选断言选了库里 0 行的「杂支」,空表也判过——补跑「资金调整」(库里 2 行)真数据复验 + API 交叉核对才算数。
3. **CashCheckPanel 不重复装配**:它的正式家在盘点页(月度 SOP D2,货和钱一起盘),p7 只做入口卡跳转——同一面板两处挂载会出两套编辑态,违背单一真相源。
4. **vite.config.ts 2 条既有 TS 错**(node:url/process,缺 @types/node)与本票无关,未动(修它要动依赖,超出「只改前端页面」边界)。
5. **本 dev 库 mode=UNSET**:结算对账区展示的是 UNSET 三态(横幅+假设对比+去定型入口),PLATFORM/DIRECT 态由 M3-3 验收已覆盖,本票不重测。
