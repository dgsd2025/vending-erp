## 五、坑(踩坑记录)

1. **JDK17 但 `maven.compiler.release=8`**:`URLEncoder.encode(String,Charset)`(Java10)、`var`、`Stream.toList()`、`List.of`、无参 `Optional.orElseThrow()` 全部不可用——编译按 Java 8 API 限制。改用 `encode(String,"UTF-8")` + `Arrays.asList` + 显式类型 + `orElseThrow(Supplier)`。
2. **POI `autoSizeColumn` headless 崩**:无字体环境依赖 AWT 会抛异常。改固定 `setColumnWidth`。
3. **盘亏 `diff_amount` 符号**:`lossStats` SQL 用 `SUM(-diff_amount)` 把亏损取正;测试造数 diff_amount 须为负(-10)才得损耗 10。
4. **现金流水方向常量**:`CashFlow.DIR_IN="收"/DIR_OUT="支"`,金额恒正;月末余额=期初+Σ(收正支负),真实账户才计入现金合计(虚拟"平台待结算"排除)。
5. **Chrome MCP 坐标/el-tabs 切换**:输入型 `left_click` 命中 el-tabs 头部未触发切换(坐标缩放歧义,截图 800px vs 视口 1360px);改用脚本 `.el-tabs__item.click()` 驱动切换取证,页面本身无 console 错(标准 el-tabs,与 Bi.vue 同构,真人可点)。
6. **真数据月份错位**:任务口述 2026-07,实际 vend_dev 种子在 2026-08;按"真数据"取 2026-08 出料,2026-07 走空月优雅路径。
